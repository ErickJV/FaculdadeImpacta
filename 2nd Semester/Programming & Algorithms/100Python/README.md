# 100Python - Exercicios de Python

Exercicios da disciplina **Programacao e Algoritmos** (2o Semestre - Faculdade Impacta).

Exercicios 01-15: cada pasta contem o codigo-fonte (`.py`) e o enunciado/fluxograma original (`.png`).
Exercicios 16-35: cada pasta contem o codigo-fonte (`.py`) e o executavel compilado com PyInstaller.
